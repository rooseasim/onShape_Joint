# onShape_Joint
🔩 Mechanical Joint with Screw Mechanism – Onshape Project

This project sho;wcases a mechanical joint built and animated using [Onshape](https://www.onshape.com/), featuring a screw-based motion system. The entire mechanism was designed, assembled, and simulated within the Onshape environment to demonstrate rotational-to-linear motion and joint articulation.
